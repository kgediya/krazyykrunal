STEP 2 OF 9 · ARCHITECTURE

Understanding the MRBD Display Physics

Unlike a phone or laptop screen, the Meta Ray-Ban Display uses a monocular optical see-through waveguide located in the right lens. Understanding this hardware makes coding for it intuitive:

⬛

1. Additive Color Physics

Black (#000000) emits 0 light from the micro-LED projector, which means the wearer sees straight through to the real world!

📐

2. Fixed 600×600 Viewport

The display is fixed at 600×600 pixels. Avoid scrollbars by designing modular, glanceable cards.

🤏

3. sEMG Neural Microgestures

The wearer navigates using thumb swipes (mapped to Arrow keys) and finger pinches (mapped to the Enter key).

Pro-tip: Always give interactive cards tabindex="0" and distinct :focus styles so the wearer knows what item is selected.
STEP 3 OF 9 · CODE STEP 1

Step 1: HTML Skeleton & Required Meta Tags

Create an index.html file. The Meta Ray-Ban Display operating system looks for specific meta tags in the document <head> to recognize and optimize your WebApp.

index.html (HTML Skeleton) 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  
  <!-- 1. Mandatory tag for Meta Wearables OS recognition -->
  <meta name="mrbd-web-app-capable" content="yes">
  
  <!-- 2. Fixed 600x600 non-scalable viewport -->
  <meta name="viewport" content="width=600, height=600, initial-scale=1.0, user-scalable=no">
  
  <title>My First MRBD WebApp</title>
</head>
<body>
  <header class="hud-header">
    <span class="badge">RAY-BAN GLANCE</span>
    <span id="clock">18:30</span>
  </header>

  <main class="hud-card" tabindex="0" id="mainCard">
    <h2>Hello XDG Mumbai! 👓</h2>
    <p>Press [Enter] or pinch fingers to trigger an action.</p>
  </main>
</body>
</html>

Key Meta Tag Breakdown

  • <meta name="mrbd-web-app-capable" content="yes">: Tells the Meta AI App and glasses to launch this in full-screen HUD mode without standard browser chrome.
  • <meta name="viewport" content="width=600, height=600...">: Locks pixel rendering to the monocular display grid.
STEP 4 OF 9 · CODE STEP 2

Step 2: Optical Waveguide CSS (Black = Transparent)

Next, we apply styles. Notice how setting background: #000000; makes the canvas 100% see-through, while translucent backgrounds like rgba(14, 22, 34, 0.9) provide rich contrast against brightly lit real-world rooms.

style.css (Optical Styling) 
/* Reset default margins and fix dimensions */
* { box-sizing: border-box; margin: 0; padding: 0; }

body {
  width: 600px;
  height: 600px;
  overflow: hidden;
  background: #000000; /* Pure black is 100% transparent in optical waveguides! */
  color: #ffffff;
  font-family: system-ui, sans-serif;
  padding: 24px;
  display: flex;
  flex-direction: column;
  justify-content: space-between;
}

/* Translucent HUD Card */
.hud-card {
  background: rgba(14, 22, 34, 0.9);
  border: 2px solid rgba(255, 255, 255, 0.2);
  border-radius: 16px;
  padding: 24px;
  outline: none;
  transition: all 0.2s ease;
}

/* Highlighted Focus State (Crucial for D-Pad / Wristband navigation!) */
.hud-card:focus, .hud-card.is-active {
  border-color: #00f0ff;
  background: rgba(0, 240, 255, 0.15);
  box-shadow: 0 0 20px rgba(0, 240, 255, 0.5);
  transform: scale(1.02);
}
Rule of thumb: Keep font sizes at or above 16px. When wearers are walking, tiny text causes eye strain.
STEP 5 OF 9 · CODE STEP 3

Step 3: D-Pad Navigation & Pinch Microgestures

The Meta Neural Wristband maps human muscle pinches directly to keyboard events. Add a standard keydown event listener:

app.js (Gesture Interaction) 
const card = document.getElementById('mainCard');
card.focus(); // Automatically focus the card on launch

// Listen for keyboard & neural band pinch events
card.addEventListener('keydown', (event) => {
  if (event.key === 'Enter') {
    // Neural Wristband finger pinch or [ENTER] pressed!
    card.style.borderColor = '#10b981';
    card.querySelector('h2').innerText = 'Pinch Detected! ✨';
    card.querySelector('p').innerText = 'Triggered an instant action in your smart glasses.';
  } else if (event.key === 'Escape') {
    // Back gesture triggered
    console.log('Back navigation requested');
  }
});

STEP 7 OF 9 · DEPLOYMENT

Step 5: 10-Second HTTPS Deployment

Meta Ray-Ban Display requires all WebApps to be served over a secure HTTPS URL. Here are the 2 fastest free ways to get a live URL in 10 seconds:

OPTION A

Vercel (Drag & Drop)

  1. Click Export index.html from Step 4.
  2. Go to vercel.com and sign in.
  3. Drag and drop your project folder onto Vercel dashboard.
  4. Your HTTPS URL is live instantly! (e.g. https://my-app.vercel.app)
OPTION B

GitHub Pages

  1. Create a new repository on GitHub.
  2. Upload your index.html file.
  3. Go to Settings ➔ Pages ➔ Deploy from Branch (main).
  4. Your URL is live at https://username.github.io/repo
